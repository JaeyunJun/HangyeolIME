# 한결 (HangyeolIME)

가볍고 조용한 macOS 두벌식 한글 입력기입니다.
**Manwoo Yi**([@navilera](https://github.com/navilera))님의 [NavilIME for Mac](https://github.com/navilera/NavilIMEforMac)을
포크해 두벌식 전용으로 다시 다듬었고, 원작의 GPLv3를 따릅니다.

## 특징

- **두벌식 전용.** 옵션 없이 표준 두벌식 하나만 합니다. 쌍자음은 Shift로 입력하고, 같은 자음을 연달아 쳐도 합치지 않습니다.
- **한/영은 macOS 입력 소스로.** 한글은 "한결 두벌식", 영문은 ABC. ⌃Space 등 macOS 단축키를 쓰고,
  앱마다 언어를 따로 두려면 macOS의 "문서의 입력 소스로 자동 전환"을 켜면 됩니다.
- **암호 입력에서 알아서 비켜섭니다.** 암호 필드·잠금 화면은 물론, 터미널의 `sudo`·`ssh`·`git`
  암호 프롬프트에서도 한글 조합을 멈춰 암호가 영문 그대로 들어갑니다. 셸 설정은 필요 없습니다.
  멈춘 이유는 입력기 메뉴의 "한결 상태"에서 볼 수 있습니다.
- **입력 소스가 막 바뀐 순간의 키도 정확히.** Raycast처럼 열리며 ABC로 바꾸는 창에 바로 쳐도
  첫 글자가 한글로 새지 않습니다.
- **입력 내용을 남기지 않습니다.** 로그·파일·네트워크로 입력이 나가는 경로가 없습니다.

### 특수키 조합 (선택)

| 키 | 입력 |
|---|---|
| Shift + ESC | `~` |
| ⌘ + ESC | `` ` `` |
| ⌘ + `\` | `₩` |

68배열처럼 `` ` `` 키가 따로 없는 키보드를 쓰는 제작자의 취향으로 넣은 기능입니다. 입력 소스와
상관없이 동작하며, 모든 키를 볼 수 있어야 해서 손쉬운 사용 권한이 필요합니다. 세 조합 말고는
키를 건드리지 않습니다. 필요 없으면 권한을 주지 않으면 되고, 한글 입력은 그대로 됩니다.

## 설치

> **지금은 직접 빌드해서 쓰는 분을 위한 저장소입니다.** 내려받아 바로 설치하는 앱은 아직 없습니다.
> 개인 Apple 개발자 계정을 마련하면, Apple 서명·공증을 받은 설치 파일을 릴리스로 제공할 계획입니다.

macOS 13.5 이상과 Xcode가 필요합니다(Apple 계정은 필요 없음).

```
git clone https://github.com/JaeyunJun/HangyeolIME.git
cd HangyeolIME
Tools/build-ime.sh
```

1. 시스템 설정 → 키보드 → 입력 소스 → **+ → 한국어 → 한결 두벌식**을 추가합니다.
   목록에 없으면 한 번 로그아웃했다 들어오세요.
2. (선택) 특수키 조합을 쓰려면 입력기 메뉴의 "한결 상태 · 특수키 조합"에서 권한을 허용합니다.

빌드 스크립트가 이 Mac 전용 서명 인증서를 만들어 서명하므로, 빌드한 앱은 그 Mac에서만 씁니다.
